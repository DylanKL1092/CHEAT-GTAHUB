# GTAHUB

Descargas y actualizaciones de GTAHUB para Windows x64.

## Descargar

Abrí [Releases](https://github.com/DylanKL1092/CHEAT-GTAHUB/releases/latest) y descargá **Nexus.exe** de la versión más reciente.

El programa requiere una licencia válida de la aplicación **menu gtahub** en KeyAuth. Cada equipo descarga las actualizaciones usando su propia conexión a Internet.

Las versiones se comprueban mediante firma e integridad antes de instalarse. Las preferencias personales se conservan al actualizar.

Este repositorio aloja los archivos de distribución. No incluye credenciales administrativas ni el código fuente del proyecto.
